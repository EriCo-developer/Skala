Copy the Skala folder to:
Windows: %APPDATA%\Autodesk\Autodesk Fusion 360\API\AddIns\
Mac: ~/Library/Application Support/Autodesk/Autodesk Fusion 360/API/AddIns/
In Fusion: Utilities tab → Add-Ins → Scripts and Add-Ins → Add-Ins tab → green "+" → select the folder.
Select it → Run (check "Run on Startup" if you want).
Click the banana icon in the navigation toolbar (bottom-center of the viewport, next to Orbit/Pan/Zoom/Fit).
