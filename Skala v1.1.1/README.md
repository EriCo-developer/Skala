# Skala — Install

1. Copy the `Skala` folder to:
   - Windows: `%APPDATA%\Autodesk\Autodesk Fusion 360\API\AddIns\`
   - Mac: `~/Library/Application Support/Autodesk/Autodesk Fusion 360/API/AddIns/`
2. In Fusion: Utilities tab → Add-Ins → Scripts and Add-Ins → Add-Ins tab → green "+" → select the folder.
3. Select it → Run (check "Run on Startup" if you want).
4. Click the banana icon in the navigation toolbar (bottom-center of the viewport, next to Orbit/Pan/Zoom/Fit). If scale is displayed incorrectly, there is a one-time calibration tool available under the add-ins tab.

## Optional: set a keyboard shortcut

Fusion doesn't let add-ins register a shortcut automatically. To add one yourself:
Tools tab → Configure → Keyboard Shortcuts → search "Skala" → assign a key.
